# CognitiaBrain Unified

Sistema inteligente de monitoramento acadêmico: **grants + artigos + IA**.

## Funcionalidades

- **Coleta automatizada:** Scrapers para FINEP, CNPq, CAPES, FAPESP, etc.
- **Classificação de relevância:** SetFit + MiniLM (few-shot learning)
- **Notificação via Telegram:** Botões inline para feedback (👍/👎)
- **Active Learning:** Retreinamento incremental com feedback do usuário
- **Dashboard Web:** FastAPI + Jinja2 + HTMX
- **Deduplicação:** Hash SHA-256 para evitar notificações duplicadas
